# Contributing

This repository is at the vision stage: there is no code here yet. What helps most right now:

- **Use cases.** Tell us what you would hand off first and what would make you trust the result, using the [use case form](https://github.com/hanlulong/econ-auto-research/issues/new?template=use-case.yml).
- **Replication packages for roadmap step 2.** Nominate a public replication package that a replication and robustness audit should be tested on.
- **What would break your trust.** Describe a failure that would make you refuse an AI-assisted result.

Please do not post a confidential manuscript, unpublished data, or anything covered by a data-use agreement. Describe the task instead.
